opzsim web

Play up to eight tracks through FX1 and FX2 before any of them goes on the OP-Z, from the keyboard or an OP-Z over MIDI. Host and engines run in WebAssembly, the same C as opzsim: 44.1 kHz, 64-frame blocks.
